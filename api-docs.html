Simple HTTP tools

lxwis API

Standalone utility endpoints adapted from the tools-tg project. No Telegram bot is involved. Send GET requests for lookups and POST JSON for tools that accept larger payloads.

Base URL:
Responses use JSON: { "success": true, "tool": "...", "result": ... }. Some providers require environment variables; see the setup notes below.

Available endpoints

AI chat

Generate a text response with Gemini.

POST/api?tool=ai_chat
{"prompt":"Explain APIs simply"}

Vision / OCR

Analyze an image or extract visible text. Send base64 image data.

POST/api?tool=vision
{"image":"data:image/jpeg;base64,...","prompt":"Read the text"}

WHOIS / RDAP

Fetch public domain registration data.

GET/api?tool=whois&domain=example.com

Photo search

Search Pixabay images. Requires PIXABAY_API_KEY.

GET/api?tool=photo_search&query=cats

QR code

Return a QR image URL for text or a URL.

GET/api?tool=qr&data=Hello

Text to speech

Return a Google Translate TTS URL.

GET/api?tool=tts&text=Hello&lang=en

Temporary email

Create a disposable inbox session.

GET/api?tool=temp_mail_gen

Check temporary inbox

Use the session token from temp_mail_gen.

GET/api?tool=temp_mail_check&token=SESSION_TOKEN

URL shortener

Shorten an HTTP or HTTPS URL.

GET/api?tool=shorten&url=https://example.com

BIN lookup

Look up public card issuer metadata using the first 6–8 digits only. Never send a full card number.

GET/api?tool=bin&bin=457173

Crypto price

Look up USD price and 24-hour change by CoinGecko coin ID.

GET/api?tool=crypto&coin=bitcoin

Random user

Generate sample user data.

GET/api?tool=randomuser&nat=us

Website status

Check a URL's HTTP status and response time. Only use on trusted public sites.

GET/api?tool=webstatus&url=https://example.com

Image hosting

Upload base64 image data. Requires FREEIMAGE_API_KEY.

POST/api?tool=imgbb
{"image":"data:image/png;base64,..."}

Pastebin

Publish text as a paste. Requires PASTEBIN_API_KEY.

POST/api?tool=pastebin
{"text":"Hello world","title":"Demo"}

Telegraph publisher

Publish a text article.

POST/api?tool=telegraph
{"title":"My post","content":"First paragraph\nSecond paragraph"}
Vercel environment variables
Required for these tools:
GEMINI_API_KEY — AI chat and vision
PIXABAY_API_KEY — photo search
FREEIMAGE_API_KEY — image hosting
PASTEBIN_API_KEY — Pastebin publishing

Add these in Vercel → Project → Settings → Environment Variables, then redeploy. Do not put secrets in HTML or commit them to GitHub. Other tools use public providers and may have rate limits or availability limits.
